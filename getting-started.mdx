في هذا الدليل ستتعلم كيف تفتح تطبيق **الذكي** لأول مرة، وتُعدّ مفتاح الذكاء الاصطناعي المجاني، وتُدخل بياناتك الافتراضية، ثم تُنشئ أول خطة درس كاملة لك في غضون دقائق — بدون أي خبرة تقنية مسبقة.

## خطوات البدء

<Steps>
  <Step title="افتح التطبيق في متصفحك">
    توجَّه إلى عنوان التطبيق مباشرةً في أي متصفح حديث على جهاز الكمبيوتر أو الهاتف:

    **[teacher22.vercel.app](https://teacher22.vercel.app)**

    لا يتطلب التطبيق تثبيتاً أو تسجيل حساب؛ يعمل بالكامل داخل المتصفح. عند أول فتح سيظهر لك معالج إعداد مفتاح الذكاء الاصطناعي تلقائياً.
  </Step>

  <Step title="احصل على مفتاح Gemini API المجاني">
    جميع ميزات الذكاء الاصطناعي في التطبيق تعمل بمفتاح مجاني من Google. للحصول عليه:

    1. اذهب إلى **[aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)**
    2. سجِّل دخولك بحسابك على Gmail.
    3. اضغط زر **"Create API key"** ثم انسخ المفتاح (يبدأ بـ `AI...`).

    لا تغلق الصفحة قبل نسخ المفتاح، فلن يظهر لك مجدداً بنفس الشكل.
  </Step>

  <Step title="أدخل المفتاح واملأ الإعدادات الافتراضية">
    في تطبيق الذكي، اضغط على أيقونة **⚙️ الإعدادات** في الشاشة الرئيسية ثم:

    1. **الصق مفتاح API** في حقل *مفتاح Gemini API*.
    2. اختر **النموذج الافتراضي** (يُوصى بـ Gemini 2.5 Flash للسرعة).
    3. عبِّئ حقول **المدرسة** و**اسم المعلم** و**المادة الافتراضية** و**المديرية**.
    4. اضغط **💾 حفظ الإعدادات**.

    <Tip>
      حرصٌ على وقتك: كلما ملأتَ الإعدادات الافتراضية بدقة، كتبها التطبيق تلقائياً في رأس كل خطة درس تُنشئها — لن تحتاج إلى إعادة كتابتها في كل مرة.
    </Tip>
  </Step>

  <Step title="أنشئ أول خطة درس لك">
    من الشاشة الرئيسية اضغط على **✏️ تحضير جديد**، ثم:

    1. اضغط على **📋 انقر هنا لإدخال بيانات الحصة** وأكمل بيانات الدرس (المادة، الصف، الشعبة، التاريخ، الحصة).
    2. اختر **مصدر المحتوى**: يمكنك اكتفاء بكتابة عنوان الدرس فقط، أو رفع صورة من الكتاب، أو استخدام المكتبة المدمجة.
    3. اضغط **⚡ توليد الخطة** وانتظر بضع ثوانٍ حتى يُنشئ الذكاء الاصطناعي خطتك الكاملة.
    4. راجع الخطة، ثم اضغط **💾 حفظ** أو **🖨️ طباعة PDF** حسب حاجتك.
  </Step>
</Steps>

## نظرة سريعة على أقسام الشاشة الرئيسية

بعد إتمام الإعداد، ستجد في الشاشة الرئيسية أيقونات الأقسام الآتية:

| الأيقونة | القسم | ما تجده فيه |
|---|---|---|
| ⚙️ | **الإعدادات** | مفتاح API والبيانات الافتراضية والنسخ الاحتياطي |
| ✏️ | **تحضير جديد** | إنشاء خطط ودروس وسبورات واختبارات |
| 🗂️ | **الأرشيف** | جميع الملفات المحفوظة منظَّمةً حسب النوع |
| 🗄️ | **دروس واختبارات** | بنك الدروس المحفوظة وأدوات الاختبارات الشاملة |
| 📊 | **الدرجات والحضور** | دفتر الدرجات وسجلات الحضور |
| 📅 | **جدول الحصص** | جدول حصص أسبوعي تفاعلي |
| 📚 | **المكتبة** | كتب المناهج المرفوعة وأداة القراءة المدمجة |
| 🗓️ | **الخطة الفصلية** | خطة توزيع المنهج على الفصل الدراسي |
| 🗣️ | **الاختبارات الشفوية** | منصة القرعة العشوائية والتقييم المباشر |
| 🧮 | **حل نماذج الاختبارات** | تحليل الاختبارات الوزارية وفرز أسئلتها |
| 📈 | **إحصائيات الذكي** | لوحة شاملة بإنجازاتك وملفاتك المحفوظة |

<Note>
جميع ميزات التوليد التلقائي (خطط الدروس، الاختبارات، الملخصات، الخرائط الذهنية، الدروس الصوتية) تستلزم وجود مفتاح Gemini API صالح في الإعدادات. الأدوات اليدوية كمحرر الاختبارات ودفتر الدرجات تعمل بدون مفتاح.
</Note>
